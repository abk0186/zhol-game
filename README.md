# Жол: дорога к Ата и Әже

Семейная браузерная игра для 8 внуков: каждый «едет» по карте Казахстана из своего города к Ата и Әже в село Кордай (или в гости друг к другу), выбирает транспорт и накручивает километры. Прогресс общий для всех устройств.

- Игра: https://abk0186.github.io/zhol-game/
- Без рекламы, без покупок, без криптовалюты и платежей. Сайт закрыт от поисковиков (`noindex`, `robots.txt`).

## Как запускать детям
1. Отправьте ссылку в WhatsApp/Telegram.
2. Ребёнок выбирает свою карточку и вводит личный код из 4 цифр. Коды задают родители в режиме «Родителям».
3. Совет: на телефоне — «Поделиться → На экран Домой», тогда игра откроется как приложение.

## Вход для родителей (только просмотр)
На экране входа есть кнопка «👪 Вход для родителей». Родитель выбирает семью и вводит код семьи (4–6 цифр):
- «Семья из Кордая» — Нурали, Тамила, Айсултан;
- «Алматы» — Аружан, Амир, Арлан;
- «Астана» — Аниса, Аиша.
- «Все дети (Асет)» — общий просмотр всех 8 детей. Карточки сгруппированы по семьям (Кордай / Алматы / Астана), лента событий — по всем детям. Код отдельный; сервер отдаёт всех детей только по нему.

Что видят родители:
- **по своим детям:** км сегодня, за неделю и всего; текущую поездку (откуда → куда, транспорт, %); города, сувениры, достижения, баланс жетонов; последние поездки и события с датами;
- **по всем детям:** карту с аватарами и направлениями, рейтинг недели, общий счётчик семьи и цель недели.

Менять ничего нельзя: ни жетоны, ни одобрения, ни курс. Данные отдаёт функция `zhol_family_login` (security definer) после проверки кода. Код хранится как bcrypt-хэш и блокируется на 5 минут после 5 ошибок. Коды семей меняет администратор: «Администратор (PIN)» → «Коды семей». Устройство запоминает вход, пока не нажать «Выйти».

## Режим администратора
Кнопка «🔐 Администратор (PIN)» внизу экрана входа. PIN по умолчанию — `0000`: **смените его сразу**. В этом режиме можно:
- одобрять или отклонять обмены жетонов, задания и шаги, отмечать «Выдано»;
- задавать курс и лимиты;
- редактировать каталог наград;
- давать бонусные задания;
- менять коды детей;
- добавлять жетоны и билеты;
- возвращать ребёнка домой.

## Навигация
- Кнопка «🏠 Домой» есть везде: в шапке игры, на экране поездки, в каждом всплывающем окне, в админке и в просмотре для родителей. Она возвращает на главную карту.
- Выход из поездки ставит её на паузу. Километры сохраняются, а продолжить можно кнопкой «Продолжить поездку».
- Кнопка «назад» браузера или Android закрывает окно или экран и ведёт на главную. На главной первое нажатие показывает подсказку «Нажмите „назад“ ещё раз, чтобы выйти». Выход из игры — только по второму нажатию в течение 2,5 секунды.

## Жарыс (челлендж)
- Вызвать можно только того, кто сейчас **в том же месте** и не в пути. У каждого может быть только **1** открытый жарыс: ожидающий или идущий.
- Вызывающий выбирает соперника, финиш и транспорт: 🚶 пешком, 🚲 велосипед, 🐎 лошадь или 🚕 машина. Транспорт одинаковый для обоих. Автобус, поезд и самолёт в жарысе не участвуют: они едут сами.
- Соперник видит вызов на главной и может принять его или отказаться. Вызывающий может отменить свой вызов. Вызов сгорает через 24 часа.
- После принятия обоим сразу ставится одна и та же поездка. Побеждает тот, кто первым доедет: это решает сервер по моменту прибытия, ничьих нет.
- **Награды:**
  - победителю — **+15 🪙** и достижение «⚔️ Победа в жарысе»;
  - второму, когда доедет, — **+3 🪙** за участие.
  - Эти бонусы идут сверх дневного лимита, но не больше чем за **3 жарыса в день** на ребёнка. Достижение (+10 🪙) даётся один раз.
- Если участник отменит поездку или сменит маршрут во время жарыса, ему засчитывается поражение, а сопернику — победа.
- Если администратор вернёт ребёнка домой или сбросит его поездку, жарыс отменяется без победителя.
- Возрастной множитель тапов сохраняется. Скорость в км ограничена сервером одинаково для всех: те же лимиты, что в обычных поездках.
- Во время гонки на полосе маршрута видно соперника и его %. Жарысы видны во вкладке «Семья» и в просмотре для родителей: например, «Амир vs Аружан: Алматы → Кордай пешком».
- Тестирование: скрытые тестовые игроки (`zhol.players.hidden = true`) видны только с флагом `localStorage.zhol_test = true`.

## Курс жетонов (примеры, меняются в админке)
| Пресет | Курс | Для кого |
|---|---|---|
| «5 ₸» | 1 🪙 = 5 ₸ | экономно; максимум 80 🪙/день ≈ 400 ₸ |
| «10 ₸» (по умолчанию) | 1 🪙 = 10 ₸ | базовый |
| «Только очки» | без денег | жетоны меняются только на привилегии/подарки |
| «Свой курс» | любое число ₸ | |

Пример каталога: +30 минут мультиков (20), выбор ужина (30), 1000 ₸ карманных (100), книга (150), кино (250), билеты на матч/концерт (400), поездка к Ата и Әже на выходные (500). Награды дороже порога (по умолчанию 30 🪙) и помеченные «крупная» ждут одобрения взрослого. Деньги и подарки выдают взрослые сами: приложение только ведёт учёт.

## Как зарабатываются жетоны
- 1 🪙 за каждые 5 км.
  - На лошади по дороге через Кордай — ×1.5.
  - На самолёте — ×0.2.
- +5 🪙 за новый город.
- +10 🪙 за новый сувенир, доставленный Әже; +3 🪙 за повторный.
- +10 🪙 за достижение.
- +2 🪙 за верный ответ в викторине; +1 🪙 за подарок или бонус в пути.
- Дневной лимит — 80 🪙. Достижения, новые сувениры и родительские задания идут сверх лимита.
- Билет на самолёт 🎫 даётся за каждые 250 км по земле.

## Транспорт
| | Как едет | км за действие (16 лет; 12–14 ×1.25; 9–11 ×1.6) |
|---|---|---|
| 🚶 Пешком | тапы / Enter | 0.1 км за тап |
| 🚲 Велосипед | левая/правая по очереди / ← → | 0.2 км |
| 🐎 Ат | тапы в ритм копыт (450 мс), пробел/↑; сила, жем | 0.6 в ритм, 0.2 мимо |
| 🚕 Такси | держать «Газ» / пробел; топливо | 1.5 км/с |
| 🚌 Автобус/поезд | едет сам, ловить бонусы | 0.8 км/с |
| ✈️ Самолёт | 1 билет, только Алматы/Астана/Тараз/Караганда | 60 км/с |

Для команды км считаются честно, без возрастных коэффициентов.

## Защита от накрутки
Всё проверяет сервер (функции Postgres `security definer`). Клиент не может сам записать жетоны.
- Не больше 12 тапов в секунду.
- Свой потолок скорости у каждого транспорта.
- Время между отправками проверяется по часам сервера.
- Лимиты в день: км и жетоны.
- В клиенте ловятся «слишком ровные» тапы. Для лошади эта проверка выключена, там ритм и так ровный.
- Код ребёнка блокируется на 5 минут после 5 ошибок, PIN родителей — на 10 минут.
- Коды и PIN хранятся только как bcrypt-хэш.

## Техника
- Статический сайт: `index.html`, `style.css`, `app.js`, `data.js` (GitHub Pages).
- База: Supabase, проект `nurali-portfolio` (`iwpmrordpxrkxlpaxutx`), **отдельная схема `zhol`**. Таблицы этой схемы не открыты через API; доступ только через RPC `public.zhol_*`. SQL лежит в `sql/`.
- Без сети: недоставленные км хранятся на устройстве и отправляются при появлении сети. Сервер засчитает их в пределах лимитов скорости.

## Как расширять
- **Новый город:**
  - `insert into zhol.nodes(id,name,kind,airport,souvenir) values ('SHY','Шымкент','city',true,'…');`
  - дороги: `insert into zhol.edges values ('TAR','SHY',<км>,'road');`
  - координаты на схеме: `XY` и `LBL` в `data.js`.
- **Новые вопросы:** массив `QUIZ` в `data.js`. Пишите только проверенные факты.
- **Новая семья:** `insert into zhol.families(id,name,sort,code_hash) values ('id','Название',3,extensions.crypt('123456',extensions.gen_salt('bf')));` Ребёнку — `update zhol.players set family='id' where id='…';`
- **Новый ребёнок:** `insert into zhol.players(id,name,age,league,home,school,avatar,color,sort,code_hash,location,visited) values ('id','Имя',10,'young','ALA','Школа','🦁','#hex',9, extensions.crypt('1234', extensions.gen_salt('bf')),'ALA',array['ALA']);` Лиги: `young` (9–11), `mid` (12–14), `old` (16).
- **Достижения:** серверная функция `zhol._check_ach` и `ACH` в `data.js`.

## Если захочется «настоящих» токенов в будущем
Детям в приложении крипта не нужна. Безопасный путь, если когда-нибудь понадобится:
1. Оставить жетоны внутриигровыми.
2. Раз в месяц взрослый сам переводит сумму по курсу на детскую карту или депозит, или покупает подарок.
3. Блокчейн можно добавить только как необменный «сертификат-значок» (NFT без цены) на кошельке родителя, без вывода денег.
